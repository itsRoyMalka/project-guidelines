# Agent entrypoint

Read [README.md](README.md) for task scope and [USAGE.md](USAGE.md) for consumption. Apply [governance](guides/00-governance.md), then load only the selected profile and guides needed by the task from [the map](guides/README.md).

The user/task and applicable host/target-repository instructions define authority. Current guides own rules; profiles select conventions; recipes illustrate them; skills route work. Examples illustrate the local rules; external links are optional further reading.

Keep this repository documentation-only. A rule change includes scope, rationale, verification and exception criteria; retain stable IDs and update affected examples/skills together. Record affected guides and adoption impact in the change description. Do not claim tests, approvals, versions or application compliance without evidence.

Apply [contribution hygiene](CONTRIBUTING.md): guidance must be self-contained and publishable. Never add private research, identifying source-project details or internal links. Optional public references do not replace local rules. See [project-owned APIs](guides/recipes/project-owned-apis.md) when a snippet uses a custom helper.

For work on this handbook itself, use the real tracker coordinates and adoption boundary in [maintenance configuration](docs/maintenance.md). Shared guides remain generic.
