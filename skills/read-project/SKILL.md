# Read a project

Read [usage](../../USAGE.md), [governance](../../guides/00-governance.md), target instructions and current issue/handoff. Inspect nearby code, contracts, data owners, tests and runtime commands before proposing changes.

Use [the guide map](../../guides/README.md) to load only affected rules. Return a short map: deployables, owning feature/action, entry-to-data path, public consumers, actual test commands, exceptions and consequential unknowns. Distinguish observed code from documented claims. Follow [WORK](../../guides/cross-cutting/06-workflow-and-docs.md); preserve a sound existing layout unless the task calls for migration.
