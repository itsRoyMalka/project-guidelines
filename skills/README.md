# Agent skills

These repository-local skills explain recurring work. An agent can read the matching `SKILL.md` directly; the files are not automatically installed globally. They contain no executable helpers.

| Task | Skill |
| --- | --- |
| Decide the first product boundaries and stack | [start-project](start-project/SKILL.md) |
| Orient in an existing codebase | [read-project](read-project/SKILL.md) |
| Plan a meaningful change | [plan-change](plan-change/SKILL.md) |
| Implement a scoped feature or fix | [implement-feature](implement-feature/SKILL.md) |
| Review a proposed change | [review-change](review-change/SKILL.md) |
| Prove a change is ready | [verify-change](verify-change/SKILL.md) |

Each skill points to the owning guide. If a task is small, keep the workflow small. Target-repository instructions and the user's actual task remain authoritative.
